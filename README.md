# MauJuara 1.0.0

Made by YNA Studio, powered by AI

Created on: November 25, 2025

## Prerequisites

- Node.js 20+ (LTS recommended)
- pnpm 9+ (project uses `pnpm-lock.yaml`)

## How to Install

```bash
pnpm install
```

## How to Run

```bash
pnpm dev
```
